# Wstaion

Wstaion is a command-line tool designed to help developers manage their development workspace more efficiently.

With Wstaion, you can quickly start the tools and applications you use in your daily workflow, helping you save time and stay focused on coding.

Instead of manually opening multiple programs every time you begin working, Wstaion allows you to configure and launch them with a single command.

## 🚧 Project Status

Wstaion is currently in its early stage of development.  
New features and improvements are planned for future releases.
